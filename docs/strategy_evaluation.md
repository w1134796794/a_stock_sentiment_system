# 策略评估台账

此页面用于先核对「盘后候选因子分数 -> 盘中确认 -> 可模拟成交价 -> 账户净值」，再讨论增加因子或调整权重。管理员在 `/strategy-evaluation` 查看。

## 使用顺序

1. 在策略配置稳定后点击「冻结新实验」，保存五个生产策略的配置摘要与因子代码摘要。
2. 选择起止日期、训练日与验证日，再点击「评估」。也可使用 `python scripts/strategy_experiment_ledger.py` 查看命令行参数。
3. 先看估值覆盖；若某日持仓没有对应的 Silver 收盘价，该日净值为空，整段收益和最大回撤不下结论。
4. 再看每个验证窗口的候选数、确认数、模拟成交数、拒单/未成交数及已平仓收益。多策略共识可分别计入候选与确认，但交易收益只归属持仓记录的主策略，账户净值只计算一次。

## 口径与限制

- 模拟盘中成交只使用同日、有接收时效且时间不早于预定成交时刻的报价，按股票最小报价单位加入滑点，并核验涨跌停；没有可靠报价时记录拒单，不生成成交。
- 历史分钟回放导入的成交标记为 `historical_minute_estimate`，不是交易所实际成交，也不能证明盘口有足够深度。
- 账户净值由成交流水逐笔重建现金与持仓，按 Silver 日收盘价估值，包含手续费、未平仓浮盈亏及回撤。页面「账户净收益」为相对初始资金的累计收益；费用统计只计所选日期内成交。
- 因子 Rank IC 读取已发布权重版本中的指标；缺少版本或有效样本时留空，不补造数值。成交样本 IC 仅描述已平仓模拟交易，不能替代全候选的未来收益 IC。
- 历史回填默认是「历史描述」。只有配置在验证期开始前冻结，且决策池、取数与快照具备当日时点证据，才标记「前瞻样本外」。这也不等于真实交易业绩。

## 数据依赖

评估需要每日决策池与页面快照、取数状态、信号与模拟交易流水、持仓账户，以及 `index_daily_silver` 和 `stock_daily_silver`。缺失时页面保留空值或标明覆盖不足；不要把空值当作零收益。
