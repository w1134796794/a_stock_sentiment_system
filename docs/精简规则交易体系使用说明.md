# 精简规则交易体系使用说明

## 1. 生产目标

生产系统只回答三个问题：

1. 今天盘后有哪些股票值得进入次日观察池。
2. 次日盘中是否出现可成交的明确买点。
3. 使用完全相同的条件回测后，策略是否有正向收益和可接受回撤。

模型概率、漂移、SHAP 和训练发布不再是生产选股的前置条件。

## 2. 三类核心策略

| 策略 ID | 中文名称 | 主要用途 |
| --- | --- | --- |
| `mainline_leader` | 主线龙头 | 识别主线中辨识度、板块地位和持续性较高的核心股 |
| `weak_to_strong` | 弱转强 | 识别分歧后修复、板块同步转强且具备分钟确认条件的股票 |
| `first_board_launch` | 首板启动 | 识别低位新启动、封板质量和板块扩散较好的首板机会 |

生产策略均为 `scope=production`、`weight_source=manual`，并受保护。
其他策略保留在策略模块中，默认属于 `research`，用于组合因子和历史实验。

## 3. 数据和因子分工

- 排序核心：各策略自身的技术、主线地位、行为阶段和封板结构因子。
- 增强证据：资金流共振、龙虎榜认可、成交额处于合理区间。
- 否决项：量能过弱或过热、拥挤衰退、龙虎榜拥挤、板块转弱等。
- 研判页面：涨停梯队和龙虎榜页面完整保留，不要求其成为候选入池门槛。

增强证据用于解释和同等条件下的优先顺序。否决项在筛选阶段生效，不允许仅凭
资金流或龙虎榜把一只不符合策略结构的股票提升为生产候选。

## 4. 日常运行顺序

1. 在“盘后取数”完成当日原始数据。
2. 在“因子计算”生成当日因子表。
3. 在“选股策略”运行三个生产策略。
4. 打开“候选股”查看去重后的 5 至 8 只决策股票。
5. 次日打开“盘中转强”：
   - “龙头弱转强观察”只观察原有近期龙头池。
   - “昨日候选 · 当日确认”只观察上一交易日决策池。
6. 只有状态变为“确认”且下一分钟存在可成交价格时，才视为可交易信号。

生产选股 API 会拒绝研究策略，防止研究组合意外混入每日候选。

## 5. 页面口径

候选股首屏只展示：

- 一句话结论。
- 命中策略和策略共识。
- 所属主线及板块强度。
- 次日确认条件。
- 失效条件。
- 建议仓位。

规则、行业、概念、增强证据和命中指标下沉到“查看规则依据”。
模型概率、预期收益、漂移和 SHAP 不在生产页面展示。

盘中页面只展示两类观察来源以及交易动作、分钟买点、实时价格、失效原因和仓位，
不再展示模型等级、历史相似样本和专业训练指标。

## 6. 统一交易契约

每个候选保留：

- 主策略 `策略ID`。
- 全部来源策略 `策略来源`。
- 允许入场模式 `allowed_entry_modes`。
- 确认截止时间和候选有效期 `strategy_execution`。

实时确认和回测均读取上述字段。回测在 T+1 加载 T 日候选，按一分钟行情确认，
信号成立后使用下一分钟开盘价成交；封板无成交量只记录“信号正确但无法成交”。

## 7. 回测验收

生产三策略回测完成后，会额外生成：

`output/backtest_results/backtest_architecture_<run_id>.csv`

页面“精简链路历史对照”比较：

- 候选数和成交覆盖率。
- 已平仓数和胜率。
- 盈亏比。
- 总收益。
- 最大回撤。

不能只用总收益判断改造成功。至少需要同时检查交易样本量、盈亏比、回撤和不同月份
的一致性。收益目标不能作为代码硬条件，也不能为了达到指定收益反向拟合历史区间。

## 8. 研究模块

策略组合、选股策略研究和策略实验室继续保留。研究策略可以组合不同因子、权重来源
和市场状态，但不会进入生产 `/screening-run`。确认研究方案长期有效后，应先将规则
归纳到三个核心策略之一，再进行完整历史回测和样本外验证。
