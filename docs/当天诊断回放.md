# 当天诊断回放

## 使用入口

管理员在“盘中转强”页点击“诊断回放”，或打开 `/intraday/replay`。

1. 选择行情日、近期龙头池或生产决策池，以及回放结束时间。候选日自动使用上一交易日，不使用当天盘后候选。
2. 股票代码为空表示当前范围的候选；指定代码必须在所选候选池中。龙头池与实时页面一样取对应 5/10/20 日池的前 30 只。
3. 默认只读取已有分钟及竞价缓存；本地 CSV 不完整时也读取采集器的 Redis 分钟缓存，并逐项检查日期、股票与完整性。勾选“补取缺失行情”，仅补取该日候选和相关同花顺成分股所需的分钟与竞价，使用已有 DataManager 逻辑，不引入原始 pytdx。
4. 点击“开始回放”，查看当前阶段、正在处理的股票、分钟进度；可以取消。刷新页面可恢复正在运行的任务。取数请求进行中时，取消会在请求返回后的检查点生效。
5. 报告展示逐股状态变化、首次确认时刻、首次观察到确认的时刻、原因、板块覆盖率、数据状态，以及价格条件的辅助诊断。原始运行证据有记录时单独展示，不替代回放结果。

报告只读诊断，不发送微信，不修改模拟账户，不写生产信号流水，不把回放信号标成实时买点。

## 固定输入比较代码

首次运行保存报告和输入副本。输入包含候选与执行配置、昨收基础、真实分钟、竞价、板块名单和成交进度模型。选择该报告为“对照基准”时，表单自动恢复基准范围；日期、股票、范围和结束时间必须一致。

对照运行直接读取保存的输入，不重新抓行情，也不重新选股。运行当前版本共享的分钟确认代码，比较每只股票的状态、首次确认时间、首次观察时间及最终原因。报告记录输入哈希和相关代码文件哈希，只有输入相同时才允许把差异视为代码回归结果。

修改 Python 代码后需要重启 Web 进程，再做对照。代码文件哈希用于版本定位，不能代替正确部署及重启。

## 证据边界

- 优先读取校验通过的真实盘前冻结包。缺冻结包时只能读取已保存的候选日候选和本地真实同花顺成分股缓存，明确标为研究输入，没有历史可用时点证明。
- 板块使用成分股同一分钟的真实价格及昨收计算，保留覆盖率、上涨比例等要求，不将候选自己的走势视为板块确认。分钟观测不是当时的实时批量快照。
- 每个确认时点仅给共享规则传入此前已收盘的分钟前缀。不插值、不用日线猜分钟买点，缺失/残缺/日期或代码错误会列为证据问题。
- 按“分钟标签后一分钟”保守认为该分钟可见。报告同时显示分钟确认标签与观察时刻，不能把标签直接当成服务器收到数据的时刻。
- 3 秒快照、历史采集器租约、接收时间及采集空窗不能从分钟数据还原。`live_runtime_verified` 固定为 false；本功能不能证明健康门禁通过，也不能验证微信渠道送达。
- 当前本地成交进度模型及研究板块名单不是历史时点证明；版本与内容保存进输入。eltdx 成交额或 VWAP 含估算时逐股注明，不能称为无偏差逐笔行情。
- “分钟数据检查通过”仅表示本次所需的格式/连续性与诊断证据检查，没有证明实时数据完整或真实可成交。

## 产物与接口

`webdata/intraday_replays/<run_id>/` 保存 `status.json`、`report.json`、`inputs.json` 和可选取消请求。状态及报告原子落盘；回放独立于模拟账户重建。使用文件互斥限制并行任务，服务重启或超过 30 分钟没有进度更新会提示任务可能中断。

- `POST /api/intraday-replay` 创建任务。
- `GET /api/intraday-replay` 最近任务。
- `GET /api/intraday-replay/{run_id}` 查看进度。
- `GET /api/intraday-replay/{run_id}?report=true` 查看报告。
- `POST /api/intraday-replay/{run_id}/cancel` 请求取消。

页面与接口均要求管理员权限，没有开放新的匿名接口。

## 服务器命令

```bash
python scripts/replay_intraday_day.py --date 20261009 --codes 002614 \
  --until 10:30 --fetch-missing --output outputs/day-20261009.json

# 修改代码并重启后，固定同一份输入做对照。
python scripts/replay_intraday_day.py --date 20261009 --codes 002614 \
  --until 10:30 --baseline outputs/day-20261009.json \
  --output outputs/day-20261009-after.json
```

CLI 同时生成 `<报告名>.inputs.json`，对照时两个文件都必须保留。服务器若禁止连接行情节点，需要先从允许采集的节点同步真实分钟缓存，不能绕过节点策略。

本地开发诊断服务使用 `--lifespan off` 启动，不启动采集器、自动盘后任务或实时模拟交易；它只供本次诊断功能测试。生产服务仍使用原正常启动方式。
