# 涨停回踩与跌停反包

两套生产策略分别使用 `limit_pullback`、`limit_reversal` 标识。盘后生成观察资格，次日以完整分钟确认；盘中反包确认不等于收盘日K反包成立。

## 数据与日常运行

- 每日 stock 因子任务同时写入 `factor_reversal_stock_wide`，覆盖当日分区，可重复执行。
- 读取截至计算日的最近80个交易日日线，至少21根有效K线；不访问未来数据。
- 需要开高低收、昨收、成交量及股票代码、名称。现有板块实时接口继续为分钟确认提供同步证据。
- 不引入 QMT、原始 pytdx 或新行情源，复用当前 eltdx 分钟链路。
- 暂不跨除权除息造成的价格断点比较原始支撑：最近20日昨收与前一收盘差异超过0.5%时跳过，避免错误锚点。ST及退市标记股票不进入这两套策略。
- 涨跌停识别复用系统现有价格限制工具；新股历史不足21根不参与。特殊交易制度股票需要完整、正确的证券状态数据。

## 涨停回踩

观察最近15个交易日内的收盘涨停事件。涨停突破此前20日平台时，保存平台上沿；否则保存涨停阳线实体中部。支撑中心在事件发生时可知，不事后移动到当天最低价。

盘后条件：涨停之后有回落、收盘未持续跌破支撑减0.5 ATR，当前价格距支撑不超过1.5 ATR。盘后不要求已经完成止跌。

分钟确认顺序：触及支撑区 → 至少三根分钟承接且低点不再下移 → 收盘突破此前三根分钟最高价 → 站上分时均价 → 当前分钟量至少为此前三分钟均量的1.2倍 → 板块同步。

支撑区为中心上下0.35 ATR，保护位为中心减0.65 ATR。确认价离中心不超过1 ATR，风险距离不超过2.5 ATR；到已知前高的空间至少为风险距离的1.2倍。收盘价跌破结构保护位即取消观察。

## 跌停反包

观察最近三个交易日内触及跌停的事件，区分收盘跌停与盘中触板。连续两个跌停事件、事件后收盘破位不进入观察。

反包目标默认是事件日阴线开盘价；一字或极小实体使用跌停前收盘价，避免零实体造成伪反包。保存实体中点、事件低点、事件日期。

分钟确认：至少三根分钟收盘站稳目标 → 低点未下移 → 放量突破此前三分钟高点且站上分时均价 → 板块同步。保护位为事件低点减0.2 ATR。价格离目标超过1 ATR或风险距离超过2.5 ATR时不追入。

## 确认与成交

默认截止14:30，可在策略组合中修改；支持09:30-11:30和13:00-14:55。有效期默认一个交易日，盘后每天重新计算结构。

实时过滤当前未完成分钟。历史模拟与实时使用同一个判定器，确认后检查下一分钟开盘成交，不能同根K线内假定低价买入。下一分钟缺失、无量、接近封死涨停、价格超出结构范围或超过截止时间时标记无法成交。

实时只允许最近完整分钟附近的新确认，不把上午旧信号按旧价格补成下午买单。同一股票同时命中多个允许模式时分别判断，按最先出现的确认处理。

## 工作台、推送与持仓

- 两套策略加入生产策略、市场阶段配置及策略组合编辑器；候选数量各最多30只。
- 符合门控的结构候选可进入扩展观察，不因普通决策池前8名上限漏扫；行业拥挤、数据不足和市场阶段限制仍生效。
- 涨停回踩允许回暖、活跃、高潮阶段的强市/震荡市；跌停反包默认只在回暖、活跃阶段启用。
- 工作台证据列出事件日、关键价、保护价；微信确认增加同样的结构信息。
- 模拟买入保存结构保护价，接入现有退出判断及卖出提醒；保留原有账户极端风险底线、T+1和持仓数量限制。
- 推送复用现有当日股票/模式去重及主题限额，不额外建立重复推送通道。

## 因子

| 因子 | 含义 |
|---|---|
| stk_limit_pullback | 回踩结构合格100，否则0 |
| stk_limit_reversal | 跌停修复结构合格100，否则0 |
| stk_pullback_contraction | 回踩量相对涨停日量的缩减评分 |
| stk_reversal_recovery | 跌停事件后跌幅收复程度，限制0-100 |

这些评分表示结构条件，不是胜率。板块相对强弱和流动性排序继续使用已有因子。

## 部署与复盘

部署后重启后端，前端静态资源随代码发布。已有服务器配置自动补入缺失的新策略，不覆盖已有同名策略参数。

已有日线数据时，对目标交易日重新运行“因子计算”，再运行“选股策略”，以生成新结构表及生产决策池；无需强制重新取数。缺历史日线时先补取。历史回测需要逐日补算因子和候选，不能用今天的结构回放过去。

新增回归用例覆盖：未来日线不影响当日锚点、午后确认、下一分钟成交、缺板块数据不买、破位取消、跳空基准变化、缺分钟不假定成交、盘中旧信号不补单。参数为可验证的初始规则，尚不代表经过历史收益优化。
