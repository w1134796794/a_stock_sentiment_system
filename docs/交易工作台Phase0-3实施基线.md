# 交易工作台 Phase 0-3 实施基线

## 1. 改造目标

本阶段只建设新的交易工作台和稳定读模型，不替换盘后取数、DuckDB 因子仓库、策略筛选、龙头池、盘中转强、实时行情和回测实现。

核心目标：

1. 用一个首屏回答“市场怎么样、今天看什么、什么条件可以参与”。
2. 将多策略候选去重后按“重点确认、盘中观察、暂不参与”组织。
3. Web 与小程序复用同一组只读应用服务和日期语义。
4. 新旧页面并行运行，任何时候都能退回现有页面。

## 2. 当前能力与所有权边界

| 能力 | 当前入口/产物 | 本阶段处理 |
| --- | --- | --- |
| 盘后取数 | `/fetch`、Silver/DuckDB | 保留，不修改 |
| 因子计算 | `/run`、`factor_*_wide` | 保留，不修改 |
| 策略筛选 | `/screening-run`、`screening/*` | 保留，消费产物 |
| 今日决策池 | `screening/decision_pool/decision_pool_*.json` | 作为工作台主要数据源 |
| 龙头池 | `/dragon`、`LeaderPoolService` | 保留独立页面，后续迁移 |
| 盘中转强 | `/intraday` | 保留独立页面，工作台提供入口 |
| 实时行情 | Redis/本地实时缓存、`/realtime` | 保留，后续叠加到工作台 |
| 涨停/龙虎榜 | `/data/limitup`、`/data/lhb` | 保留研判入口 |
| 模拟交易 | `/backtest` | 保留，不改变撮合口径 |

## 3. 日期与数据契约

- `trade_date`：盘后候选和决策池所属交易日。
- `market_date`：实时行情所属自然交易日，仅实时接口使用。
- `generated_at`：产物生成时间，不等同于行情时间。
- 页面查询只读取本地产物，不在请求链路调用 Tushare、adata、easyquotation 或 pqquotation。
- 数据缺失时返回明确的 `data_status` 和 `data_completeness`，不使用其他日期静默填充。

## 4. Phase 0 基线

- 原首页：`/`，保留现有市场概览。
- 新工作台：`/workspace`，与旧页面并行。
- 只读聚合：复用 `MobileReadRepository` 和 `MobileReadService`。
- 稳定 API：新增 `/api/v1/workbench` 与候选详情接口。
- 权限：工作台对管理员和只读用户开放，沿用数据库权限矩阵。
- 回滚：删除工作台菜单和路由即可，不影响任何数据任务和旧页面。

## 5. Phase 1-3 验收标准

1. 新工作台可以选择已有决策池交易日。
2. 首屏展示市场状态、涨跌停、炸板率、仓位尺度和风险提示。
3. 候选按三层行动组展示，同一决策池记录只出现一次。
4. 候选卡片只显示行动信息；专业证据通过详情抽屉查看。
5. 详情包含策略共识、主线题材、确认条件、失效条件、仓位和规则证据。
6. 普通页面请求不调用外部行情供应商。
7. 桌面和手机宽度下不发生横向溢出或文字遮挡。

## 6. Phase 4-8 边界

| 阶段 | 目标 | 数据来源 | 请求约束 |
| --- | --- | --- | --- |
| Phase 4 | 迁入主线、涨停梯队、龙头和龙虎榜摘要 | 决策池、Silver、`LeaderPoolService`、龙虎榜本地视图 | 懒加载，不调用外部接口 |
| Phase 5 | 候选卡片叠加实时价格、涨幅和确认状态 | Redis/进程内服务器实时快照 | 仅交易日 09:30-15:00 自动刷新 |
| Phase 6 | 候选详情增加行业概念、日 K 和完整个股入口 | DuckDB `stock_daily_silver` | 只读本地历史行情 |
| Phase 7 | 日期、视图、行动分组和搜索交互收口 | 工作台读模型 | 不改变候选与交易规则 |
| Phase 8 | 缓存、回归测试、前端构建和桌面/手机验收 | 30 秒短 TTL 与稳定 API 契约 | 不缓存外部调用结果 |

Phase 4-8 继续保留 `/data/limitup`、`/data/lhb`、`/dragon`、`/intraday`、`/stock/{code}` 等专业页面；工作台只提供摘要、决策入口和快速跳转，不重复实现原模块。

### 数据语义

- 主线观察是决策池主线与现有龙头所属题材的聚合，不用“融资融券”等通用标签重新推断题材。
- 涨停梯队只使用 `limit_up_pool_silver`，不使用涨幅阈值模拟涨停。
- 实时卡片展示的是 `market_date` 行情；候选仍属于 `trade_date`，两者不混用。
- 历史日期、非交易日、09:30 前和 15:00 后均停止自动轮询，手动刷新仍只读取缓存。
- 日 K 来自 `stock_daily_silver`，页面请求不补抓 Tushare 数据。
