# 首板高风险策略实验报告（2026-07-21）

## 1. 目标与实验约束

目标是检验 2026 年 6 月至 7 月期间，短线策略能否在真实交易约束下达到 20% 以上收益。实验遵守以下约束：

- 模型训练样本截止 2026-05-31，验证区间为 2026-06-01 至 2026-07-20。
- 候选只读取各策略已经通过必选条件与排除条件的 `final` 结果。
- T 日盘后生成候选，T+1 使用一分钟行情按时间顺序确认，下一分钟开盘价成交。
- 封板买不到、分钟数据不足或确认失败的信号不计买入。
- 未修改生产策略配置，所有计划和报告保存在 `webdata/experiments/strategy_factor_oos`。

## 2. 关键诊断

分钟行情补齐后共有 899 条策略候选，1546 个分钟需求全部命中缓存。因此原回测成交少的主要原因不是分钟数据缺失，而是：

- 弱转强跌破前 5 分钟低点或 10:00 前未确认。
- 强势延续缺少真实 09:25 竞价量证据。
- 开盘幅度不属于策略允许的入场模式。
- 组合仓位、策略持仓数和板块集中度限制。

六策略标准组合仅取得 `+0.30%`，5 笔平仓，说明弱转强和主线龙头在该区间拖累了首板收益。

## 3. 达到 20% 的挑战组合

| 项目 | 设置 |
| --- | --- |
| 策略 | 仅首板启动 |
| 模型 | ExtraTrees 回归 |
| 训练样本 | 152 笔真实分钟确认成交样本 |
| 特征 | 全量已登记个股、板块、行为和资金因子 |
| 每日候选 | 模型前 3 名，预测收益不低于 0.3% |
| 入场 | 按开盘形态自适应选择弱转强、强势延续或高开加速 |
| 持仓 | 最多 2 只，单票上限 80%，账户风险预算 8% |
| 总仓位/板块上限 | 98% / 90% |

结果：

| 指标 | 结果 |
| --- | ---: |
| 总收益 | **+21.53%** |
| 最大回撤 | -5.33% |
| 平仓数 | 4 |
| 胜率 | 100% |
| 期末资金（10 万起始） | 121,530.70 |

四笔平仓为：生益科技 `+0.31%`、有研新材 `+14.50%`、旗滨集团 `+3.98%`、先导基电 `+9.77%`。收益主要来自有研新材和先导基电，集中度很高。

模型的重要因子依次为：打板身位、近 5 日拥挤衰减、行为修复、封板时间、流通市值适配、市场关注、注意形成和一致加速。

### 3.1 为什么只有 4 笔平仓

`4 笔平仓` 是挑战账户在 80% 单票仓位、最多持有 2 只等账户约束下的最终成交结果，并不代表两个月只有 4 次策略机会。旧回测流程先执行仓位和账户门禁，再检查分钟入场信号，导致“出现有效信号但账户无法继续买入”没有被单独统计。

修正后，使用首板启动和主线龙头候选、10% 单票上限进行覆盖率诊断，2026-06-01 至 2026-07-20 得到：

| 漏斗环节 | 数量 |
| --- | ---: |
| 策略候选 | 114 |
| 有效分钟信号 | 27 |
| 其中可按下一分钟开盘价成交 | 25 |
| 信号正确但无法成交 | 2 |
| 账户实际买入并完成交易 | 15 |
| 有效信号后被账户约束拒绝 | 10 |

其中首板启动产生 15 个分钟信号，主线龙头产生 12 个。账户拒绝主要来自单票预算不足以购买 1 手高价股，而不是策略没有给出机会。覆盖率诊断组合取得 `+1.18%`、胜率 `60%`、最大回撤 `-1.46%`；它用于证明交易机会存在，不是新的收益最优组合。

回测页面和结果文件现统一展示“策略候选 -> 有效分钟信号 -> 账户实际买入 -> 完成交易”四层口径。后续比较策略时必须同时查看机会覆盖率和账户成交率，不能只看平仓笔数。

## 4. 稳健性检验

| 扰动实验 | 收益 | 最大回撤 | 平仓数 | 结论 |
| --- | ---: | ---: | ---: | --- |
| ExtraTrees + 全特征 | +21.53% | -5.33% | 4 | 达到收益目标，但样本太少 |
| ExtraTrees + 策略核心特征 | +7.86% | -8.26% | 5 | 对特征集合敏感 |
| RandomForest + 全特征 | +7.69% | -8.27% | 4 | 对算法敏感 |
| ExtraTrees/RandomForest 集成 | +5.21% | -10.38% | 4 | 集成后优势消失 |
| 训练截至 4 月、独立回放 5 月 | +0.69% | -19.02% | 6 | 跨月稳定性不合格 |

因此，`+21.53%` 只能认定为高风险挑战结果，不能认定为稳定、可复制或可上线的收益能力。

## 5. 自动晋级规则

实验器现已自动检查：

- 总收益不低于 20%。
- 至少 20 笔平仓。
- 最大回撤不低于 -15%。
- 胜率不低于 45%。

全部满足才标记为 `publishable`，否则标记为 `challenge_only`。本次 20% 组合因只有 4 笔交易，状态为 `challenge_only`，不会写入生产策略配置。

## 6. 下一轮有效改进

1. 扩充首板真实成交标签，目标至少 100 笔样本外成交，并覆盖强、震荡、弱三种市场。
2. 单独训练“是否能够确认成交”的 Meta-Label，先预测可成交性，再预测成交后的收益。
3. 将竞价缺失与竞价不合格分开；缺失时只允许使用明确命名的开盘 5 分钟确认模型，不能伪造竞价证据。
4. 按月滚动发布模型，要求最近 3 个样本外月份至少 2 个月为正，且合计平仓不少于 20 笔。
5. 生产仓位先使用 20%–35%，高风险 80% 仓位只能放在挑战账户，不能作为默认值。

```powershell
  --max-position 0.80 --max-total-position 0.98 --max-sector-concentration 0.90
```
