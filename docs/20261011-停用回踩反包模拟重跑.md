# 停用回踩、反包后的模拟重跑

## 配置与区间

- 本地默认配置及生效配置均停用 `limit_pullback`、`limit_reversal`；不删除因子和历史记录。
- 启用：`mainline_leader`、`weak_to_strong`、`first_board_launch`。
- 区间：20260701 至 20261009，67 个真实交易日，初始资金 100 万元。
- 使用当前模拟规则：最多三仓、单票目标 34%，原有市场门禁、分钟确认、策略退出、T+1、手续费及滑点；不是前述调参实验的小风险仓位组合。
- 独立账户：`history_20261011_204616`，名称“停用回踩反包 · 三策略重建”。原模拟账户及手工成交未修改。

## 核验与修复

61 份历史计划、292 条计划记录均不含被停用策略的来源或入场模式。完整运行中的候选证据样本数按引擎实际使用的候选日及可交易样本计，区别于计划文件总行数。

首次导入发现除权参考价调整后的理论持仓数量被取整、并被限为原买入数量，现金回流不足，导致 10 条买卖记录漏导入。修复仅作用于成本匹配的完整历史退出，保留原始卖出价、理论调整数量、成本、费用和盈亏；普通卖出、部分卖出及手工交易仍沿用原整股规则。

修复后同一批已完成回测重新导入：76 条成交逐笔核对数量及盈亏，账户现金与报告相差不足 0.00001 元。理论调整数量在页面单独标注，不当作券商实际登记股数。

最新候选日 20261009 的选股、决策池及页面快照亦已按三个启用策略刷新。

结果与证据：`outputs/disabled_structural_replay_20261011/result.json`、`plan_audit.json`、`run.log`、`import_retry.log`、`refresh_latest.log`。首轮调参实验的修复核验已按用户新指令中止，不宣称其全部完成。
