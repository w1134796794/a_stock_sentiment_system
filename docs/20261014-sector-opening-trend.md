# 板块开盘走强确认

## 生效规则

板块同步接受两条路径，任意一条通过即可：

1. 原红盘广度路径：上涨占比至少 55%，成分股平均涨幅非负，板块方向非负。
2. 新开盘走强路径：同一组成分股的平均相对真实开盘涨幅大于 0，且相对 3 分钟前净抬升。不要求板块相对昨收红盘，也不要求 55% 红盘率。

覆盖率门禁不变；新路径要求前后共同观测成分至少覆盖真实名单 60%，且至少 2 只。前后样本交集固定，开盘价发生变化的样本不参与，避免名单或基准变化制造上涨。

`core/signals/sector_sync.py` 保存共用规则及版本 `ths_red_or_open_rising_3m_v2`。实时确认与当天诊断回放都调用同一函数。旧的纯候选同行样本路径仍只能提供部分证据，不能凭少数候选冒充全板块覆盖。

## 数据和时间

实时使用成分股实际行情中的 `open_price` 和 `last_price`，只积累真实、同日、新鲜的观测。需要存在 3 分钟前的源时点观测；快照轮询允许最多 30 秒边界误差。无历史时点时不回填、不前向填充，不补发采集空窗中的买点。

诊断使用同日实际开盘字段及当时已收盘的分钟，仅比较当前分钟和恰好 3 分钟前的分钟。集合竞价以外的首分钟收盘价不当作板块真实开盘价。当日日线只读取 `open`，不使用当日收盘价、最高价或最低价参与判断。开盘数据来源和开盘映射写入回放输入哈希；保存输入对照不会重新请求数据。

盘后补取的实际开盘价可以进行规则诊断，但不能证明当时的数据到达、Redis 租约或消息发送。旧回放没有开盘证据时不能凭空使用新路径；需要补数据后建立新报告。不同输入哈希的报告不冒充同输入代码对照。

## 不变的约束

- 仍仅使用核验的同花顺 `8...` 板块及其成分，不接纳 `700...` 分类。
- 个股分钟突破、VWAP、确认截止时间、下一分钟成交和账户风控不放宽。
- Redis/采集器健康门禁和行情新鲜度不关闭。
- 本次诊断不交易、不通知，不以单个案例调参或宣称盈利改善。

历史收益引擎的旧同行样本结果不等价于具备全板块开盘曲线的新路径评估，不能直接拿旧收益声称新规则有效。
