# 确认质量五阶段优化

本次落地的是独立研究对照，不是自动修改实盘或默认模拟账户。生产分钟确认默认仍为 legacy，原有账户、34%三仓配置及通知不变。

## 对照顺序

| 组 | 对照组 | 唯一新增规则 |
| --- | --- | --- |
| 原34%三仓 | 无 | 修复后执行基准 |
| 固定风险 | 原34%三仓 | 每笔目标风险为账户权益0.5%，计入成本 |
| 真突破 | 固定风险 | 完成分钟收盘严格站上突破关键价，且不低于VWAP；仅最高价穿越不算 |
| 持续确认 | 真突破 | 首次真突破之后再等2个连续完成分钟，收盘守住关键价和VWAP；最后时点重验板块 |
| 回踩确认 | 真突破 | 10分钟内回踩关键价±0.2%并守住；之后另一个完成分钟收盘突破前一分钟高点，重验板块 |
| 隔夜风险 | 持续确认 | 增加区间前跳空压力距离、组合与同板块风险预算 |
| 分策略选股 | 隔夜风险 | 按策略增加已有、候选日可用因子的质量门禁 |
| 失效退出 | 分策略选股 | 买入下一交易日上午，连续2分钟收盘跌破突破关键价和VWAP，下一可成交分钟退出 |

持续和回踩是平行实验。后续组预先固定采用持续分支，不能看完这段历史的收益再改用更好的分支。各组共享同一候选、行情、执行配置和起始资金；改变确认/仓位后账户现金及可接纳候选自然不同，属于账户级对照，不能误称逐笔完全匹配的统计实验。

## 分钟证据及成交

- 弱转强、强势延续和高开加速的突破关键价为开盘前5分钟最高价。
- 涨停回踩和跌停反包的关键价为结构锚点与触发前3分钟最高价中的较高值。
- 不跨午休累积持续分钟；午休取消待确认。真正缺分钟则报告证据不足。
- 等待期间跌破结构保护价取消；未站稳/未回踩完成不是数据缺失。
- 无有效成交量的等待分钟不计入持续或回踩确认；没有后续有效买点时保留具体质量否决及关键价，不用笼统的截止超时覆盖。
- 完成最终确认后，只能用下一连续分钟的开盘价模拟成交，并保留原有量、涨停封锁、滑点、费用及截止时间限制。
- 板块证据按最终确认时点复核；缺板块不能用盘后涨幅替代。
- 保存首次触发时间、最终确认时间、突破关键价、确认模式和模拟成交时间。
- 成交进度门槛沿用首次触发时的既有规则；此轮不同时改变量能阈值，避免混淆对照变量。

## 隔夜风险仓位

仅取买入日前20个交易日的官方开盘/昨收参考价，至少10个有效样本。历史逆向跳空幅度为 max(0, 1-open/pre_close)，取90%经验分位数，并设置8%压力下限。压力距离为该值与原硬止损距离的较大值，再计入成本。

新增仓位取原固定风险仓位与以下预算允许金额的较小值：单笔0.5%、组合总压力风险1.5%、重叠板块压力风险0.75%。已持仓用冻结在入场时的压力距离占用预算；未知板块按同一未知分组处理，不视为无相关风险。最终仍受100股整手、现金、三仓和其他现有约束限制。

这些是预先声明的研究参数，不是用旧亏损回测拟合出的最优值。压力预算不能保证实际损失上限：T+1、跌停无成交、极端跳空仍可能超预算。

## 分策略质量

| 策略 | 新增门禁 |
| --- | --- |
| 涨停回踩 | 回踩缩量质量≥50、板块相对强度≥50 |
| 跌停反包 | 反包恢复质量≥50、板块相对强度≥50 |
| 弱转强 | 行为修复≥60、板块相对强度≥50；原历史龙头身份门禁继续保留 |
| 主线龙头 | 主线龙头身份≥70、板块持续性≥50、板块相对强度≥50 |
| 首板启动 | 不追加质量阈值，样本过少；保留已有规则 |

使用冻结计划中的原始因子分数，不回看后续收益重算。低分记录策略否决，缺因子或非有限分数记录证据缺失，不能当零分静默跳过。

## 退出规则

新增失效退出仅在买入后的下一交易日生效，截止10:00。不得在买入当日卖出。连续两分钟失效后，下一连续分钟有成交量、未封跌停且未超时才模拟卖出。若更早出现硬止损或原有退出，以更早事件为准；不允许后来高点改变先前退出判断。其他原有止损、移动止盈和退出规则不变。

## 使用

策略评估页选择“冻结回放对照”，再选择“确认质量·五阶段八组”，设置区间后冻结并运行。页面显示独立账户净值、7个阶段对照、滚动验证、分策略/市场阶段样本以及缺失证据。续跑同一冻结实验可恢复逐日检查点，不重复成交。

命令行：

```powershell
.venv\Scripts\python.exe scripts/replay_research.py freeze --start 20260701 --end 20261009 --suite confirmation_quality --amount-profile outputs/research_validation_20261010/minute_amount_profiles.json
.venv\Scripts\python.exe scripts/replay_research.py run <experiment_id>
.venv\Scripts\python.exe scripts/replay_research.py verify <experiment_id>
```

上述本地模型路径只是已有合格历史模型的示例；服务器须有对应模型及其源分钟文件，不能仅复制一个JSON绕过源文件校验。CLI按当前盘后产物生成新计划；如需复用上一轮私有修复计划，应使用 ReplayResearch.freeze 显式传入同一私有计划、因子库和配置，以维持同条件对照。

`--optimization-config parameters.json` 可传入预先决定的部分参数，未提供项补齐默认值。所有有效参数、配置、行情文件及执行代码版本均参与冻结校验。默认 CLI 仍为基础四组对照，五阶段方案必须显式选择。

禁止用区间结束后训练的成交进度模型补历史信号。显式历史模型需提供区间前完整分钟训练及源文件哈希证明；否则区间所需成交进度证据仍会阻断。缺失后先修复缓存，再冻结新实验，不能修改已封存证据包。

## 解释结果

这是已观察历史上的探索性研究，不是新的前瞻样本外结果。不能承诺提高收益或稳定盈利。

训练默认30日、间隔5日、验证10日。训练期成熟平仓至少20笔且净收益为正、盈利因子大于1才允许在该窗口选优；验证期收益不参与选择。验证成熟样本至少30笔、窗口至少3组才能获得历史对照标记；依然不自动授权生产发布。各组账户连续运行，滚动窗口是观察窗口，不是已拼接的切换策略账户。

若缺证据或候选被跳过，显示“数据不完整”，不对不完整的阶段组合计算收益差。样本不足、无正期望证据允许“不选优”，不能强行推荐相对少亏的一组。仓位改善回撤不代表选股具备正期望。

旧完成实验保留可读，但执行代码变化后不能继续旧实验。须重新冻结，不能关闭代码校验以接力。
