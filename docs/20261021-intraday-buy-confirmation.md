# 盘中走强买点：公开心得与量价确认实现

## 资料边界

公开“游资心法”经常混有转述、未经审计的收益故事和事后解释。本文只使用可定位到作者的原帖和媒体原始采访，不用财富传说为阈值背书。原帖可公开读取的部分有限，没有绕过登录限制。下面的具体倍数和百分比是工程上的试运行假设，不是任何交易者公开认证的固定公式，也未证明能提高收益。

- 炒股养家《论反弹》（2011-06-14）按市场阶段区分强势股反抽、新热点、超跌与主流热点。可借鉴的是先判断环境和机会类型，而不是看到上涨就买。原帖：https://www.tgb.cn/a/1ykw1M5al2J
- 炒股养家《核辐射防护 美罗药业》（2011-03-14）展示了把事件催化、题材及同类强势股放在一起分析的做法。这是一则历史观点，不是验证过的普适策略。原帖：https://www.tgb.cn/a/1ykvN6xgNZa
- 退学炒股《我和小明》（2017-02-06）公开开头用“小明”叙述冲动跟随及盈利后又亏回的经历。可借鉴的工程原则是预先定义条件、避免临场改变模式；不能据此杜撰某个量比或VWAP参数是作者的方法。原帖：https://www.tgb.cn/a/1ykBGTOOa5F-8
- 中国基金报《A股打板策略经历迭代与重构》（2026-04-13）原始采访讨论情绪博弈、执行时延、微观结构及因子衰减。它提示不能将封板或历史“心法”视为可保证成交和稳定盈利的规则。原文：https://www.chnfund.com/upload/epaper/2026-04-13/A0420260413C.pdf

## 提炼成系统规则

1. 环境与主线优先：保留现有市场环境、候选、策略及真实板块确认逻辑。
2. 个股走强必须有结构：收盘站过关键位和VWAP，不把瞬时最高价刺破当成确认。
3. 观察资金是否持续承接：使用实际分钟成交量，区分放量站稳与缩量回踩后的再次放量。
4. 买点与成交分开：确认以后下一分钟或下一有效快照才模拟成交；涨停无成交证据、价格过远仍不成交。
5. 不为补买而改变预案：策略允许的入场模式、截止时间、新鲜度、真实板块门槛不变；三板负反馈仍是独立扣分因子。

## 本次调整范围

只修改现有弱转强、强势延续、高开加速三种模式内部的确认方式。没有新增策略，没有让九阳股份等个股因上涨而绕过策略允许模式，也没有更改已有涨停回踩、反转等独立结构策略的定义。

新增 `volume_price` 确认器，复用 `backtest/confirmation_quality.py`，由实时、诊断回放和生产回测共同调用。原 `legacy`、`close_breakout`、`sustain`、`pullback` 对照规则保留。

## 两条确认路径

共同前提：原模式的开盘范围、结构、累计成交进度、板块等条件先通过；突破分钟收盘在关键价和VWAP之上。

| 路径 | 条件 | 最早确认 |
| --- | --- | --- |
| 放量站稳 | 突破分钟量 / 前3个连续分钟均量 >= 1.2，包含突破分钟在内连续2根已完成分钟收盘站稳关键价和VWAP | 第二根已完成分钟 |
| 回踩再突破 | 初次突破之后5分钟内，另一个分钟触及关键价上下0.2%范围且量不超过初次突破分钟的80%；再后一个分钟收盘越过前一分钟高点并相对前3分钟均量放大到1.2倍 | 回踩之后的再突破分钟 |

回踩与再突破必须是不同的已完成分钟，不从同一根分钟线的高低点臆测先后顺序。弱转强的关键价取开盘前5分钟高点与昨收的较高者，避免初次收复昨收、确认时又跌回昨收以下。开盘强势延续在已有竞价证据允许的VWAP承接分支中，确认关键价采用该触发时已知的VWAP；其他突破分支仍用开盘前5分钟高点。

等待期间失守VWAP或超出关键价回踩容忍范围，当前结构失效；跌破结构保护价取消。确认窗口必须连续，不跨缺失分钟或午间休市累计。最终确认时重新检查板块状态与原模式的累计成交进度，不沿用初次触发时的通过结果。

确认价和执行价均不得高于已知VWAP的2%、或高于突破关键价的1.5%。这些上限只限制当前买点，不永久否决该股票，后续有效回踩仍可重新评估。

## 可调整参数

统一配置位于 `config/risk_control.yaml` / `RiskConfig`：

| 参数 | 当前试运行值 |
| --- | --- |
| entry_confirmation_mode | volume_price；可切换legacy作对照 |
| entry_sustain_minutes | 2，包含突破分钟 |
| entry_volume_lookback | 3，不包含当前分钟 |
| entry_min_local_volume_ratio | 1.2 |
| entry_pullback_window | 5 |
| entry_pullback_tolerance | 0.002 |
| entry_pullback_max_volume_ratio | 0.8 |
| entry_max_vwap_distance | 0.02 |
| entry_max_breakout_extension | 0.015 |

参数页提供确认方式菜单及常用阈值，保存时拒绝非有限数、不合法窗口和未知模式。比例按小数填写，不是百分数的整数形式。

## 数据与一致性

- 真实开盘价仍来自已有当日开盘证据，不使用第一分钟价格代替。
- 局部成交量按股数统一，手/股不同来源先换算；不把估算成交额当成真实资金净流入，也不伪造主动买入占比。
- eltdx分时点不是完整分钟OHLC；能确认的是实际观测到的点位，不推断未观测到的分钟内路径。
- 回测只用触发至确认前缀；未来价格和成交量不能改变已完成确认。执行价格限制使用确认时已知的VWAP，不拿下一分钟收盘计算VWAP反过来决定开盘能否成交。
- 三秒快照只能细化已通过的分钟结构；不能越过分钟条件。等待期间结构失效或换了确认关键位，旧触发不能继续成交。
- 记录 `confirmation_policy`、`confirmation_reason`、`initial_confirm_time`、`breakout_level`，与最终确认、成交时点分开，供回放与流水核对。
- 当前YAML显式启用新规则；没有记录确认方式的旧冻结配置继续解释为legacy，不事后改写历史。当日已经冻结旧配置的生产回放不会因升级代码自动变成新规则实验。
- `MinuteEntryEvaluator()` 和直接构造的旧研究回测仍保持legacy；通过统一风控配置构造的新回测与实时使用同一确认参数。

## 验证边界

回归测试检查假突破、量缩量增、连续分钟、保护位、板块复核、追价、因果性、实时/回测时点一致、快照失效与配置兼容。这些是工程正确性验证，不是收益验证。

上线前仍应做独立时间段的旧/新规则对照，统计触发数量、实际可成交比例、费用后收益、最大不利波动、回撤及各市场阶段表现。不能根据少数事后上涨样本调参，更不能因为新规则暂未触发就放宽缺数据门槛。本次未发送消息、修改账户或部署服务器。
