| 主模块 | 模块内视图 |
| --- | --- |
| 交易工作台 | 交易总览、龙头池、候选池、盘中确认、实时行情、行情证据 |
| 市场复盘 | 涨停梯队、板块主线、龙虎榜 |

原 URL 保留，通过顶部标签进行路由切换，只加载当前视图。不新增策略执行、接口补取、账户变更等副作用。

权限仍由原 capability 控制。旧平铺菜单的默认隐藏项可在对应模块标签中发现，已保存的显式隐藏/禁止访问配置仍生效。只读角色不显示策略研究与行情采集，系统设置仅保留允许访问的页签。

## 日期与状态

- 涨停、板块、龙虎榜互切保留交易日，历史链接继续有效。
- 工作台、龙头池、候选池、盘中确认之间保留名单日，不擅自改成行情日。
- 最新概览不再占用模块标签，旧首页地址仍兼容。
- 路径按最长匹配选择归属，诊断回放属于回测验证，不会同时高亮盘中确认。
- 收起侧栏只保存本地显示偏好；手机保留抽屉式菜单。

## 内容优先级

1. 首屏先呈现有来源的结构或状态摘要：主线、龙头、确认状态、风险或数据缺失。
2. 紧接关键对象：高度梯队、候选名单、资金动向或回测结果。
3. 展开查看条件、个股证据、成交或归档明细；原始宽表及日志不占首屏主位。

本次首先在涨停、板块页实现展示层摘要，并直接渲染默认分类，避免先显示空壳再请求同一份归档。摘要只使用当前页面已有行，不改变计算规则、排序和正式买点门槛；缺失不冒充零值或确认。

## 产品价值表达

- **发现**：市场主线与龙头角色，让观察范围清楚可查。
- **确认**：区分候选、正式确认、不能执行与取消，以条件和风险证据解释状态。
- **验证**：用冻结输入、真实归档、回放对账和完整回测样本验证结论。

后续演示可沿“市场复盘 → 龙头/候选 → 盘中确认 → 回测验证”展开。卖点依靠可复现的真实链路，不使用精选收益、虚构实时证据或无样本支持的胜率承诺。
