# 收益改进受控实验

## 目的和边界

上一轮质量基准在 20260701—20261009 的收益为 -2.2653%，最大回撤 3.2913%，34 笔平仓，仍没有正期望证据。本轮检验三个独立假设，不修改生产策略、默认模拟账户、手续费或数据完整性要求，不保证盈利。

这段历史已用于形成假设。再次滚动验证仍属于已使用历史上的探索研究，不是未见样本外检验。必须另用未参与设计的历史区间或未来数据确认，不能用本轮最高收益自动配置生产策略。

## 五组对照

| 实验组 | 控制组 | 唯一改变 |
| --- | --- | --- |
| strategy_quality | 无 | 原分策略质量、持续确认和隔夜风险基准 |
| reversal_regime | strategy_quality | 仅跌停反包限定候选日为强市、情绪活跃 |
| pullback_quality | strategy_quality | 仅涨停回踩增加结构、缩量和入场空间检查 |
| exit_failure | strategy_quality | 原次日两分钟跌破突破位及均价的失效退出 |
| exit_patient | exit_failure | 仅调整失效退出容错，其他退出规则保持一致 |

不按股票、具体日期排除亏损，不将三种改动叠加成一个事后最优组合。反包市场门禁不影响弱转强、主线龙头、首板和回踩策略。主线及首板的单笔亏损不是删除策略的依据。

回踩质量和退出容错各自是一组预先固定的规则包，本轮只比较整个模块的作用，不能把改善单独归因于某一个阈值。

## 回踩质量

- 使用候选日已知的涨停事件、支撑、保护位、ATR、前高，不用入场日收盘回填结构。
- 缩量因子至少 70，沿用原因子公式 `100 * (1.5 - 回踩平均成交量 / 涨停事件量)`，对应回踩量不超过事件量的 0.8 倍；它不是当日分时量比。
- 候选收盘距支撑不超过 1 ATR。
- 在分钟确认且获得含买入滑点的模拟入场价后，检查 `(已知前高 - 入场价) / (入场价 - 结构保护位) >= 1.5`。
- 前高空间只是一项几何过滤，不等于目标一定到达或最终盈亏比，不放松原分钟、板块、价格涨跌停和账户风险门禁。
- 缺少结构、结构日期错误、非有限数明确阻断；结构不合格属于规则否决，不当作数据缺失。

## 失效退出容错

仅买入后的下一交易日生效，不做 T+0：

- 09:40 才开始累计失效分钟，之前的跌破不累计到缓冲期之后。
- 连续三个有成交量的完整分钟，收盘价均低于突破位与累计均价各 0.3%，才确认失效。
- 价格恢复、无成交量或时间不连续会中断累计。
- 使用下一分钟开盘价成交，截止 10:00；缺下一分钟、不满足可成交价格和跌停约束时不虚构成交。
- 原硬止损、追踪退出等更早触发的规则仍优先；容错不是推迟硬止损。

## 风险和发布

原单笔 0.5%、组合 1.5%、关联板块 0.75% 压力风险预算保持不变，沿用至少十个区间前日线样本及八个百分点隔夜压力下限。这些是仓位约束，不是最大损失保证。

参数随实验冻结并校验合同。每天保存独立账户检查点，重复运行不应改变已完成状态。候选和持仓仍采用严格证据模式，持仓分钟缺口只通过真实补取、新建冻结实验解决。

训练 30 日、隔离 5 日、验证 10 日。训练期至少 20 笔平仓、正账户收益及利润因子超过 1 才可选择；没有足够样本或正期望时不选优。至少三个验证窗口、累计 30 笔验证平仓仍只是历史比较门槛，不会自动授权生产。

## 使用

策略评估选择“冻结回放对照”，对照方案选“收益改进 · 三项假设五组”。页面显示五个账户、四组配对差异、滚动窗口、按策略与市场阶段的结果及冻结参数，并提示仍须未见样本验证。

完整复现命令：

```powershell
.venv/Scripts/python.exe scripts/validate_confirmation_quality.py --baseline webdata/replay_research/0fc378fbc9413309f08a3e0db3b7d4a2 --private outputs/research_validation_20261010 --output outputs/return_refinement_20261011 --suite return_refinement --fetch-missing
```

输出目录中的 `progress.json`、`run.log` 和 `validation_summary.json` 给出进度与结果。代码或证据版本改变后必须使用新输出目录、新实验，不能接力到不同版本的合同。

反复在同一历史上择优会产生过拟合风险，参见 [Bailey 等的回测过拟合研究](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。本轮不进行自动遍历或以盈利为止的调参。

## 审计与结论

- 两个不变控制组的经济成交和每日净值均复现上一轮结果。
- 五个完整账户检查点在重复运行后字节完全一致。
- 157 次实际模拟买入逐笔核对突破、连续两分钟收盘与均价、下一分钟开盘及滑点，未发现时序违规。
- 新增真实分钟为 20260723 / 002841，240 点完整，分钟末价及官方日线收盘均为 45.90。
- 比较 326238 条共用冻结证据，只有这一条分钟记录由空变为完整；另有 96 条停牌查询时间刷新，状态及其他内容未变。旧封存实验没有被修改。
- 157 项相关测试、限定文件 Ruff、编译检查及桌面/手机六个页面场景通过。本地 8013 预览已重启，未开启自动采集、调度或历史交易通知。

结论：可以继续研究市场阶段适配和回踩选股门禁，不能宣布正期望或稳定收益曲线。下一次应固定本轮参数，使用未参与设计的区间或未来数据，不继续在同一区间上自动择优，也不自动将两个收益较好的规则叠加到生产策略。
