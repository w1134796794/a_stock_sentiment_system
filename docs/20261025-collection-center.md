# 行情采集中心

入口统一为 `/market-collection`，仅管理员可操作。旧 `/fetch` 跳转盘后页签；旧 `/market-backfill` 保留并默认打开补数页签，历史任务链接不变。

| 页签 | 数据范围 | 执行边界 |
| --- | --- | --- |
| 盘后 | 原始行情、基础资料、板块、资金数据与 Silver 标准层 | 独立取数子进程；不计算因子、不选股、不训练模型 |
| 盘前 | 已生成两池名单、上市状态、板块对照与当日采集名单 | 独立准备子进程；缺少盘后策略产物时记录缺失，不运行筛选或回补盘后输入 |
| 盘中 | 个股快照、板块通道、分钟兜底、归档队列及心跳 | 仅监测原有独立采集与归档服务；不通过网页启动策略或重启系统服务 |
| 补数 | 已保存的历史龙头池、决策池个股分钟 | 读取名单、独立补数、校验冻结；回测仍需在历史回测中显式启动 |

## 独立调度

- `AUTOMATION_DAILY_TIME` 默认 `20:00`，只启动 `automation_daily_worker.py --phase postclose`。
- `AUTOMATION_STRATEGY_TIME` 默认 `20:15`，独立检查本地 Silver 是否就绪，再启动 `--phase strategy`。数据缺失只记录 `waiting_data`，下一轮检查，不调用采集器。
- 两阶段使用独立状态、结果与日志，分享盘后写入任务锁，避免并发计算/写入。完成采集不会调度策略；策略缺数据不会调度采集。
- 策略阶段使用 `ETLDailyPipeline(None)`，不注入行情 Provider；按本地输入计算因子、执行选股。选股不再隐式调用板块补取或案例行情归档，也不冻结次日采集计划。
- 盘前冻结、上市证据与板块准备只在独立盘前任务进行。默认趋势评分口径不额外抓取全量 THS 成分宽度；旧版冻结输入仍保留其宽度要求。
- Web 的实时页面只读取已有冻结计划，缺失时等待独立任务，不再自行创建或补取。
- 旧的完整复盘/回测/研究串行路径仅供显式 `--phase legacy` 兼容调用；新调度不再隐式生成日报、启动自动回测或研究取数。旧 `AUTOMATION_AUTO_BACKTEST` 设置不再触发后台回测，兼容脚本需显式传 `--auto-backtest`；状态接口保留 `legacy_auto_backtest_setting` 供排查。日报、回测及研究需显式运行。

## 状态口径

- 基础表就绪与全部原始接口完成分开呈现。接口返回部分数据但报错时保留错误，不视为接口完整成功。
- 缺少进程心跳或心跳超时不能标绿；内存缓存不能冒充 Redis 共享存储。
- 历史日期不使用当前实时心跳证明当时采集成功。页面明确区分当前服务状态与历史行情证据。
- 页面 GET 及状态轮询不创建行情 Provider、不补数、不运行策略、不发交易通知。
