# 三板后强负反馈：禁买与反抽退出

## 已确认口径

- 第1、2、3日为连续三个交易日收盘封住涨停；第3日前一个交易日不涨停，避免把四板、五板断板混为三板组。
- 第4日收盘相对该日昨收的跌幅达到股票涨跌停幅度的50%，触发强负反馈。普通10%涨跌幅股票对应跌5%；20%和30%股票分别对应跌10%和15%。
- 第5、第6个交易日禁止新买入，覆盖弱转强、强势延续、高开加速和结构买点，评分、板块强度及3秒快照不能抵消否决。
- 第4日不因后来取得的当日收盘数据而被事后禁买；第7日不再命中本规则，但仍须通过其他全部入场与风险条件。
- 若持仓实际买入日在第4日，第5日最新有效价格较该日真实开盘价反弹达到2%，触发全量退出判断，不要求回本，不等待再次回落。
- 原有硬止损、结构保护和移动止损仍优先；新规则不延缓止损。T+1、停牌、行情时效及模拟成交校验照常生效。

## 参数

统一来源为 `config/risk_control.yaml`，通过 `RiskConfig` 冻结和投影：

```yaml
three_board_feedback_enabled: true
three_board_feedback_limit_fraction: 0.50
three_board_rebound_exit_gain: 0.02
```

2%反抽触发价向上取到最小价格单位，避免四舍五入后未到2%就提前触发。仅比较当时最新价格，不用全天最高价或未来分钟的最高价。通知及模拟交易并不等同于真实券商订单成交。

## 证据与一致性

历史日线只读取行情日前六个真实交易日，盘中不发起远程历史行情请求。盘前冻结包保存涉及候选及持仓的历史日线；盘中、当天回放和生产回测使用同一判定函数。回放输入包括历史记录与阈值，保存后重放不读取现在的行情来补写历史。

缺少必要日线、日历或存在冲突记录时，不能把“不知道”当作“未命中”，生产入场保持缺证据状态。旧冻结包缺少新历史字段时，需要重新采集完整的新版本证据；不覆盖旧冻结包来冒充原始输入。

标准生产入口及由 `RiskConfig` 构造的回测默认启用。直接构造旧版 `BacktestConfig()` 或独立分钟形态评估器仍为明确的旧研究口径；新研究需通过统一配置或显式开启本开关。

直接指定 `BacktestConfig(production_rules=True)` 时也默认开启；可显式传入 `three_board_feedback_enabled=False` 做对照实验。配置页面“风控参数”已提供同名开关及两个阈值，阈值必须是(0, 1]内有限数值。

规则集版本为 `production_shared_v5_board_feedback`。入场流水保存 `board_feedback`，退出证据保存负反馈上下文与反抽阈值，便于核对拒绝新仓和已持仓退出的不同原因。

## 醋化股份回归案例

本地日线记录：2026-10-12、13、14连续涨停；10月15日收盘从15.80跌至14.22，跌10%。对应：

- 10月15日为第4日：本规则不提前否决当日入场。
- 10月16日为第5日：禁买；若10月15日买入，真实开盘13.80元，反抽触发价14.08元。
- 10月19日为第6日：禁买，周末不计入窗口。
- 10月20日为第7日：本规则解除，不代表其他条件允许买入。

上述是用户指定规则的代码回归案例，不构成收益改善、普遍A杀概率或实际可成交价格的统计证明。
