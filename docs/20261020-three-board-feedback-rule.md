# 三板后强负反馈：扣分因子与反抽退出

## 已确认口径

- 第1、2、3日为连续三个交易日收盘封住涨停；第3日前一个交易日不涨停，避免把四板、五板断板混为三板组。
- 第4日收盘相对该日昨收的跌幅达到股票涨跌停幅度的50%，触发强负反馈。普通10%涨跌幅股票对应跌5%；20%和30%股票分别对应跌10%和15%。
- 按2026-10-21修正口径，第5、第6个交易日标记负向风险因子，命中时从0至100候选强度分扣除配置分数，不对任何入场模式执行一票否决。
- 第4日不能使用后来取得的收盘数据事后标记风险；第7日不再命中该因子。所有日期仍须满足独立的价格、板块、行情时效及其他入场条件。
- 若持仓实际买入日在第4日，第5日最新有效价格较该日真实开盘价反弹达到2%，触发全量退出判断，不要求回本，不等待再次回落。
- 原有硬止损、结构保护和移动止损仍优先；新规则不延缓止损。T+1、停牌、行情时效及模拟成交校验照常生效。

## 参数

统一来源为 `config/risk_control.yaml`，通过 `RiskConfig` 冻结和投影：

```yaml
three_board_feedback_enabled: true
three_board_feedback_limit_fraction: 0.50
three_board_feedback_score_penalty: 20.0
three_board_rebound_exit_gain: 0.02
```

2%反抽触发价向上取到最小价格单位，避免四舍五入后未到2%就提前触发。仅比较当时最新价格，不用全天最高价或未来分钟的最高价。通知及模拟交易并不等同于真实券商订单成交。

## 证据与一致性

历史日线只读取行情日前六个真实交易日，盘中不发起远程历史行情请求。盘前冻结包保存涉及候选及持仓的历史日线；盘中、当天回放和生产回测使用同一判定函数。回放输入包括历史记录与阈值，保存后重放不读取现在的行情来补写历史。

缺少必要日线、日历、存在冲突记录或可选历史读取失败时，因子值为null、状态为未评估，扣分为0；不把“不知道”记成“未命中”，也不阻断分钟买点判断。它单独列在因子提示中，不列为回放硬失败。旧冻结包缺少历史字段时同样处理，不从现在的数据补写冻结输入。

20分是试运行的配置值，不是已通过收益回测证明的最优值。原始因子值为命中1、未命中0、未评估null，方向为negative。缺数、关闭及未命中均不扣分。扣分仅应用一次，强度分下限为0；旧冻结配置没有扣分字段时保持0，不追填20分。原有日线筛选分和权重不被重写。

标准生产入口及由 `RiskConfig` 构造的回测默认启用。直接构造旧版 `BacktestConfig()` 或独立分钟形态评估器仍为明确的旧研究口径；新研究需通过统一配置或显式开启本开关。

直接指定 `BacktestConfig(production_rules=True)` 时也默认开启；可显式传入 `three_board_feedback_enabled=False` 做对照实验。配置页面提供同名开关、两个阈值及扣分；两个比例阈值必须在(0, 1]内，扣分必须在[0, 100]内，均须有限。

规则集版本为 `production_shared_v6_optional_feedback_factor`。入场流水保存独立的 `board_feedback` 因子，不写入 `entry_veto_reason`；退出证据仍保存负反馈上下文与反抽阈值。历史门禁记录保持原样，需用新代码重新回放，不能把旧流水改成没有拦截过。

## 醋化股份回归案例

本地日线记录：2026-10-12、13、14连续涨停；10月15日收盘从15.80跌至14.22，跌10%。对应：

- 10月15日为第4日：不使用当日未来收盘标记本因子。
- 10月16日为第5日：命中负向因子并按配置扣分；若10月15日买入，真实开盘13.80元，反抽触发价14.08元。
- 10月19日为第6日：命中负向因子并按配置扣分，周末不计入窗口。
- 10月20日为第7日：不再命中本因子，不代表其他条件允许买入。

上述是用户指定规则的代码回归案例，不构成收益改善、普遍A杀概率或实际可成交价格的统计证明。
