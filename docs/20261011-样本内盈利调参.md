# 样本内盈利调参记录

## 边界

本轮依据用户“继续调参直到历史盈利”的要求开展。此前已看过同一区间的八组确认质量实验、五组收益改进实验，因此本轮是明确的样本内拟合，不能作为未见样本验证，也不承诺未来盈利或稳定收益。

生产策略配置、默认模拟账户、手工成交和真实通知不修改。新建独立研究账户，不以日线补分钟买点，不跳过缺失候选或持仓证据。正常手续费、印花税、滑点、T+1、涨跌停不可成交约束保留。

## 冻结输入

- 区间：20260701—20261009，67 个交易日。
- 源实验：`ac64fdc13fbd106d7694c3669043e8ed`，完整候选控制组，上一轮严格数据基准。
- 使用已修复分钟缓存、候选日前确定的因子、策略结构与市场阶段，冻结后只读证据。
- 初始资金 100 万；每笔风险预算 0.5%、组合 1.5%、同板块 0.75%，隔夜压力距离至少 8% 加成本，最多三仓。
- 候选及因子权重不重新筛选；本轮改变的是入场过滤、确认窗口及退出研究规则。

## 运行前登记的五组

| ID | 研究规则 | 对照 |
| --- | --- | --- |
| strategy_quality | 原策略质量、两分钟持续确认、隔夜风险仓位 | 上一轮同名组 |
| combined_quality | 组合反包市场门禁与回踩质量门禁 | strategy_quality |
| combined_patient | 组合门禁，并加次日失效退出容错 | combined_quality |
| combined_sustain3 | 组合门禁，持续确认由两分钟变三分钟 | combined_quality |
| combined_weak_regime | 组合门禁，弱转强仅允许候选日弱市/退潮阶段 | combined_quality |

组合门禁：反包仅候选日强市/情绪活跃；回踩缩量因子至少 70、候选收盘距已知支撑不超过 1 ATR、实际入场至已知前高的空间/结构风险至少 1.5。

容错退出：仅 T+1；09:40 起收盘持续三分钟低于突破关键价和均价线 0.3%，有效成交量，下一可成交分钟退出，10:00 截止；硬止损优先。

弱转强阶段过滤来自已经看过的历史亏损归因，尤其容易过拟合，必须单独保留报告，不包装为新发现的通用规律。

## 本轮选择规则

保留五组完整结果及全部尝试，按全区间账户净收益排序。仅完整回放、无缺证据跳过、净收益为正、至少 10 笔平仓、最大回撤不超过 5% 的组进入“历史盈利候选”。

这只是本轮实验筛选标准，不代表统计显著，也不代表生产准入。滚动窗口仍保留为回溯诊断，因为同一段历史已经参与假设设计，不能声称这些窗口是未见数据。

本轮为登记的四个变体加一个对照，不无限追加参数，不隐去失败尝试。达到历史盈利后停止继续追逐更高的样本内收益，下一步应冻结配置，再收集未使用数据验证。
